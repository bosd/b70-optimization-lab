# A321 prereg: does removing the certified W13 delta make MTP0 faster?

Written while A321 loads.

**The change.** One line of the tuned map: `W1_CONFIG.BLOCK_SIZE_N` 32 → 64, so W13 runs
the same tile as W2 and the phase delta stops doing anything. No source change — 64 is
already an allowed tile — so the head stays the certified `2a372e86` and A304 is the control
at 33.322/33.447 (2K) and 33.471/33.410 (4K) through the identical frozen client.

**Two hypotheses, opposite signs.**

*The offline ladder* ranks W13 at 77.30 µs per layer at 32 against 91.98 at 64, so removing
the delta should cost 14.68 µs per layer, 0.70 ms per step, about **−0.8 tok/s** → near 32.6.

*The inversion* says that ladder is anti-predictive here. It ranked 16 ahead of 32 by 8.18 µs
per layer and the server ran 16 **2.05 tok/s slower**; the server preferred the larger tile
by roughly a quarter of a tok/s per µs of predicted disadvantage. On that reading 64 should
beat 32 by something like **+1 to +2 tok/s** → 34.5 to 35.5.

**Decision rule, fixed now.** A result near −0.8 restores the offline ladder's credibility
for the upward direction and confirms the certified map. A result above +0.5 says the
certified delta is a pessimization and removing it is a free win on a published record — and
because it *removes* a tuning rather than adding one, the resulting configuration is simpler
than what is published, not more exotic. Anything between −0.5 and +0.5 is spread: A304's own
rows differ by 0.125, so I will call that no effect and stop extrapolating the inversion.

**Exactness.** Unchanged, predicted and required: `afffd2110812…` at exact-2K and
`1d833e5f4633…` at exact-4K. The N tile does not touch any element's K loop, which held
across A317, A318 and A320.

**If it wins.** A321 already runs the full client, so a win needs its gates green and the
hashes unmoved, then the standard deterministic repeat and fresh-server pair before the MTP0
record is republished. The W13-N64 selection verifier is written and was dry-run to
`status pass`, key 1, W13 N=64, all preservation checks true, before the packet was frozen.

**Caveat.** This is one more draw from a distribution that has embarrassed the offline probe
four times. The inversion is a hypothesis fitted to a single reversal, and a second data
point is exactly what it needs.
